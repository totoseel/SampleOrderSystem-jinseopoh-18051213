# 반도체 시료 생산주문관리 시스템 — 프로젝트 요약

## 1. 배경 및 목적

가상의 반도체 회사 **S-Semi**는 연구소·팹리스 업체·대학 연구실 등에 반도체 시료(Sample)를 납품한다.
주문량 급증으로 엑셀·메모장 기반 관리의 한계(주문 누락, 공정 현황 파악 불가, 불필요한 추가 공정 발생)가 드러나
**콘솔 기반 생산주문관리 시스템**을 개발하기로 결정.

---

## 2. 역할 구성

| 역할 | 행동 |
|------|------|
| **고객** | 필요한 시료를 이메일로 요청 |
| **주문 담당자** | 요청에 맞게 주문서 작성·관리 |
| **생산 담당자** | 개발 시료 등록, 주문 수신 후 승인 또는 거절 |

---

## 3. 시스템 개요

- **인터페이스**: 콘솔(CLI) 기반, 담당자가 직접 명령 입력
- **생산 라인**: 단일 라인, 시료를 하나씩 생산, 주문이 들어온 시료에 대해서만 생산

---

## 4. 주문 상태 흐름

```
RESERVED → (승인) → 재고 충분? → YES → CONFIRMED → RELEASE
                              → NO  → PRODUCING → CONFIRMED → RELEASE
         → (거절) → REJECTED
```

| 상태 | 의미 |
|------|------|
| `RESERVED` | 주문 접수 |
| `REJECTED` | 주문 거절 (모니터링 제외) |
| `PRODUCING` | 주문 승인 완료 + 재고 부족으로 생산 중 |
| `CONFIRMED` | 주문 승인 완료 + 출고 대기 중 |
| `RELEASE` | 출고 완료 |

> `REJECTED`는 정상 흐름 외의 상태이며 모니터링에서 제외한다.

## 5. 메인 메뉴 구성

| 메뉴 | 기능 |
|------|------|
| 시료 관리 | 새로운 시료 등록, 목록 조회, 이름 검색 |
| 시료 주문 | 고객 주문 접수 (RESERVED 생성) |
| 주문 승인/거절 | RESERVED 목록 확인 후 승인·거절 처리 |
| 모니터링 | 상태별 주문 수 및 시료별 재고 현황 확인 |
| 생산라인 | 현재 생산 중인 시료 및 대기 큐 확인 |
| 출고 처리 | CONFIRMED 주문에 대해 출고 실행 → RELEASE |

메인 화면에는 **시스템 현황 요약**(등록 시료 수, 총 재고, 전체 주문 수, 생산라인 대기 수)을 표시한다.

## 6. 기능 명세 상세

### 6-1. 시료 관리

시료(Sample)는 시스템의 가장 기본 단위. **등록된 시료만 주문 가능**.

| 서브메뉴 | 설명 |
|----------|------|
| 시료 등록 | 시료 ID, 이름, 평균 생산시간, 수율 입력 |
| 시료 조회 | 전체 목록 + 현재 재고 수량 표시 |
| 시료 검색 | 이름 등 속성으로 특정 시료 검색 |

- **수율(Yield)**: 정상 시료 / 총 생산 시료 (예: 100개 중 90개 정상 → 0.9)

### 6-2. 시료 주문 (접수)

고객 요청을 받아 주문 담당자가 주문 생성.

- 입력값: **시료 ID**, **고객명**, **주문 수량**
- 생성 직후 상태: `RESERVED`
- 주문번호 형식 예시: `ORD-YYYYMMDD-NNNN`

### 6-3. 주문 승인/거절

`RESERVED` 목록을 확인 후 처리.

- **승인 시 재고 분기**:
  - 재고 충분 → 즉시 `CONFIRMED`
  - 재고 부족 → 생산라인 자동 등록 + `PRODUCING`
- **거절** → 즉시 `REJECTED`

### 6-4. 모니터링

| 하위 기능 | 내용 |
|-----------|------|
| 주문량 확인 | 상태별(RESERVED / CONFIRMED / PRODUCING / RELEASE) 건수 표시. REJECTED 제외. |
| 재고량 확인 | 시료별 현재 재고 + 주문 대비 재고 상태 표기 |

**재고 상태 라벨**:

| 라벨 | 조건 |
|------|------|
| 여유 | 주문 대비 재고 충분 |
| 부족 | 주문 대비 재고 수량 부족 |
| 고갈 | 재고 수량 = 0 |

### 6-5. 생산라인

- **단일 라인**, 재고 부족분만 생산
- **실 생산량**: `ceil(부족분 / (수율 × 0.9))`
- **총 생산시간**: `평균 생산시간 × 실 생산량`
- 생산 완료 시: `PRODUCING` → `CONFIRMED` 자동 전환
- **스케줄링 전략**: FIFO (선입선출)
- 표기 정보: 현재 생산 중인 주문 정보(주문번호, 시료, 진행률, 완료 예정 시각), 대기 큐 목록(순서, 주문번호, 시료, 주문량, 부족분, 실생산량, 예상 완료 시각)

### 6-6. 출고 처리

- `CONFIRMED` 상태 주문 목록 표시
- 특정 주문 선택 → 출고 실행 → `RELEASE` 전환
